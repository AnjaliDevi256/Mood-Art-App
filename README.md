# MoodArt AI

MoodArt AI is a full-stack MERN application that generates AI-powered artwork from user prompts. Users can enter a text description, generate images based on their ideas, and manage generated artwork through an interactive gallery.

## Features

- AI Image Generation from Text Prompts
- User-Friendly Interface
- Dynamic Image Gallery
- Download Generated Images
- Remove Images from Gallery
- Responsive Dark-Themed Design
- Real-Time Image Display

## How It Works

1. Enter a text prompt describing the desired image.
2. Click the **Generate Art** button.
3. The application sends the prompt to the backend API.
4. An AI-generated image is created based on the prompt.
5. Generated images are displayed in the gallery below.
6. Users can:
   - Download generated images
   - Remove images from the gallery
